# Discipline Specifications Directory (`docs/plans/disciplines/`)

This directory stores specialized subagent deliverables generated during the multi-agent design panel phase before production code is written:

1. `YYYY-MM-DD-[feature]-ux-spec.md` (Drafted by UX Interaction Specialist)
2. `YYYY-MM-DD-[feature]-visual-tokens.md` (Drafted by Visual Design Specialist referencing `docs/DESIGN.md`)
3. `YYYY-MM-DD-[feature]-accessibility-spec.md` (Drafted by Accessibility / WCAG Specialist)
4. `YYYY-MM-DD-[feature]-database-security.md` (Drafted by Database / RLS Specialist)

Subagents output here to keep the parent agent context window clean and prevent token bloat.
